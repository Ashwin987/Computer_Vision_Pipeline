# Dashboard-only requirements. Community Cloud's default Python is currently
# 3.14.7 (no version pin exists in this repo), and the CV pipeline's own
# stack (inference/onnxruntime in particular) has zero published wheels for
# 3.14 - installing it here made the WHOLE file unresolvable (pip/uv install
# is all-or-nothing), which was blocking even unrelated packages like pypdf
# from ever installing. The dashboard process itself never imports any of
# that stack directly - it only shells out to run_cv_analysis.py as a
# subprocess for live upload, which is already the explicitly-not-guaranteed
# path on this platform's free tier. So it's dropped here rather than fighting
# a Python-version pin: the guaranteed curated-match demo path never touches
# it, and live upload was already expected to be impractical on ~1GB RAM.
# (The dormant Dockerfile path uses python:3.11-slim, where this stack WOULD
# install fine - if that path is ever revived, re-add the CV-pipeline block
# that used to live below, either back into this file or a separate one.)
#
# Also dropped: the --extra-index-url .../whl/cpu line for CPU-only torch.
# It's gone now anyway since torch/torchvision aren't needed by the dashboard
# process itself, but worth recording why even if they come back: Community
# Cloud's build got a 403 Forbidden querying that index, and uv's
# dependency-confusion protection (first-index-wins across multiple
# --extra-index-urls) then locked onto a stale package version found there,
# cascading into an unrelated unsatisfiable-version error.
